## Not done

- The contracts have not been audited.
- The deployment is testnet only.
- Agents cannot file approval requests.
- Pre-submission refusals are kept only in the browser where they occurred.
- Activity reads RPC events as far back as the node keeps them—up to about seven days; the public testnet node has kept as little as about a day. There is no indexer.
- One worker runs one agent and one service.
- The five registered services pay demo addresses controlled by the deployer; there are no outside merchants.
- **First write after a deploy is expensive.** The first policy write extended the contract's storage lifetime and charged 368.39 test XLM in fees ([transaction cb406cd0…](https://stellar.expert/explorer/testnet/tx/cb406cd008132e81e0259569b1971a8d07232a0735e457178354589bbddfa8f0)); a simulated policy write now costs about 1 XLM.
