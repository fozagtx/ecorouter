## Not done

- The contracts have not been audited.
- The deployment is testnet only.
- Agents cannot file approval requests.
- Pre-submission refusals are kept only in the browser where they occurred.
- Activity reads RPC events that go back about seven days; there is no indexer.
- One worker runs one agent and one service.
- The five registered services pay demo addresses controlled by the deployer; there are no outside merchants.
