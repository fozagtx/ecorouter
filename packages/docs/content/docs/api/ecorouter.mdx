## Constructor validation

`new EcoRouter(config)` throws `TypeError` when:

- `account` or `sessionSecret` is empty, or fewer than two providers are given.
- Two providers share the same `id`.
- An endpoint is not HTTPS, or its hostname is local (localhost, private ranges, link-local, IPv6 ULA).
- A `qualityScore` is outside 0 to 1.
