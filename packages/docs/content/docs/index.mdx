title: Introduction
description: What EcoRouter is and how the pieces fit together.
---

EcoRouter is a local TypeScript SDK for capability-based purchasing by autonomous agents. Instead of hardcoding an API vendor, your agent asks for a capability such as `web.search`. The SDK probes configured providers over HTTP 402 (x402 V2 `exact`), validates each offer against your local spend policy and the on-chain Soroban mandate, picks the best value deterministically, settles the payment in USDC on `stellar:testnet`, and normalizes the response into one predictable shape.

Everything runs on your machine. There are no hosted services, no registries, and no custodial wallets. Payment authorization is enforced on Stellar by the `ecorouter-account` Soroban smart account, which gates every transfer through `__check_auth` against a mandate you control.
