EcoRouter is a shared USDC account on Stellar testnet. Each spender has an on-chain policy enforced by the `team-account` contract: allowance, per-payment cap, payment count, expiry and approved service ids.

<Callout type="warn" title="Honest status">
EcoRouter runs on **Stellar testnet only** and the contracts are **not audited**. Use test funds.
</Callout>

## Start here

Install Freighter, switch it to Testnet, connect the app, then add testnet USDC from Settings. Add spenders with service-specific policies before making a payment.
