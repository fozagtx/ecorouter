Agent SDK

Install and use the EcoRouter TypeScript SDK for team-account agent payments.

The package ecorouter exposes TeamAgent for the deployed team-account contract. It uses @stellar/stellar-sdk and defaults to the testnet values in TESTNET. The TypeScript source is in packages/sdk/src/index.ts.

Install

The package is ESM and builds TypeScript from src/ to dist/.

Use from any language

The ecorouter-agent binary has a one-shot pay subcommand. It reads AGENT_SECRET and the optional TEAM_ACCOUNT_ID and RPC_URL from the environment, calls TeamAgent.pay once, and writes the outcome as one JSON line. bigint fields are decimal strings. Exit status is 0 for paid, 3 for refused, 4 for pending, 2 for invalid arguments, and 1 for an unexpected error.

--key is optional and must be 64 hexadecimal characters when supplied. Reuse the same key to safely retry an unknown result. A caller can parse the JSON line and branch on status:

With no subcommand, the same binary starts the scheduled worker described in The worker.

Example

TeamAgent exposes the public address as address; use the same address when the owner creates the agent policy. teamAccount, rpcUrl and networkPassphrase are optional overrides in the constructor.

Public API

USDC amounts passed as strings are decimal USDC values with at most seven fractional places. A bigint is already in the token's base units. scheduleKey returns a SHA-256 hex digest of ecorouter:v1:${team}:${agent}:${service}:${slot}.

The i128 monetary values are bigint.

PayOutcome is a discriminated union:

StatusFieldsMeaning
paidkey, txHash, explorerUrl, receiptThe transaction succeeded on testnet.
refusedkey, rule, reason, overByThe contract refused the payment; no funds moved.
pendingkey, txHashConfirmation was not seen within about 60 seconds. Reconcile before retrying.

Rule and ruleReason cover the 25 AccountError codes. See Error codes.

Safe retry

pay() does not resend a transaction automatically. If the result is unknown, call reconcile(key). A safe retry calls pay() again with the same key. The contract rejects a reused key with rule 7 (DuplicatePayment) if the first transaction already paid; reconcile() checks is_key_used to distinguish that case. Reads, simulations and account-sequence lookups retry network errors up to three times with backoff.

Offline tests are in packages/sdk/test/sdk.test.js. The testnet integration script is packages/sdk/test/live.testnet.mjs; it is gated by ECOROUTER_LIVE=1.

Source: packages/sdk/src/index.ts; contract methods check, pay and is_key_used in contracts/team-account/src/lib.rs.
