API Reference

Providers

The HTTP contract a web.search provider must implement.

HttpWebSearchProvider (in providers/web-search.ts) talks to providers over plain HTTP. Any endpoint that implements this contract works with the router.

Challenge response

A compliant provider replies HTTP 402 with a payment-required header containing a base64 (or base64url) encoded JSON PaymentChallenge:

A non-402 status, a missing header, or malformed base64 JSON raises InvalidPaymentChallengeError for that provider.

Success response

Capability

The Capability type is "web.search". Providers are matched to requests by exact capability string before being probed.
