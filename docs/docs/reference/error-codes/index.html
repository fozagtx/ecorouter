Error codes

The team-account contract errors and the short titles shown in the app and SDK.

The numeric values are AccountError discriminants in contracts/team-account/src/lib.rs. Titles match packages/app/src/engine/rules.ts; packages/sdk/src/index.ts exports the same mapping through Rule and ruleReason.
