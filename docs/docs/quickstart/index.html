Quickstart

Install EcoRouter and run your first execution.

Install

Prerequisites

You need three things before the router can pay for anything:

  1. A deployed ecorouter-account Soroban contract holding USDC on stellar:testnet, with an active mandate created via create_mandate (see Contract).
  2. A session keypair whose public key is the mandate's session_public_key.
  3. A PaymentClient implementation. The SDK defines the interface but does not ship a concrete client. You supply the code that reads mandate state and submits the authorized transfer (see Payment Client).

Configure the router

The constructor validates the config: at least two providers, unique ids, HTTPS endpoints on public hostnames, and qualityScore between 0 and 1.

Execute

Call router.execute

Read the result

Reusing an executionId is safe: a completed execution returns its cached result. An id that is running, failed, or whose settlement state is unknown throws.
