Errors

Every EcoRouterErrorCode, its class, and when it is thrown.

All SDK errors extend EcoRouterError (alias ArbiterError), which carries code: EcoRouterErrorCode and an optional executionId.

CodeClassThrown when
NO_ELIGIBLE_PROVIDERNoEligibleProviderErrorNo provider survived capability, challenge, quality, and validation filters in execute.
INVALID_PAYMENT_CHALLENGEInvalidPaymentChallengeErrorA provider did not return HTTP 402, omitted or malformed payment-required, or the challenge failed shape, network, scheme, asset, payTo, or amount checks.
POLICY_EXCEEDEDPolicyExceededErrorChallenge amount exceeds policy.maxSpendUsdc.
MANDATE_EXCEEDEDMandateExceededErrorAmount exceeds maxPaymentAtomic or remainingAtomic.
MANDATE_EXPIREDMandateExpiredErrormandate.expiresAt is at or before now.
MANDATE_REVOKEDMandateRevokedErrorThe mandate is revoked.
PAYMENT_AUTHORIZATION_ERRORPaymentAuthorizationErrorYour PaymentClient threw it; signing or authorization definitively failed.
PAYMENT_SETTLEMENT_ERRORPaymentSettlementErrorYour PaymentClient threw it; the transfer definitively failed.
PAYMENT_SETTLEMENT_UNKNOWNPaymentSettlementUnknownErrorauthorizeAndSettle threw anything else; settlement may have succeeded.
PROVIDER_EXECUTION_ERRORProviderExecutionErrorThe paid provider request failed (non-2xx or transport error).
PROVIDER_RESPONSE_ERRORProviderResponseErrorThe paid response did not match { results: [{ title, url, snippet }] }.

PaymentSettlementUnknownError

Beyond code and executionId, it carries:

Prop

Type

Executions that end settlement_unknown cannot be retried under the same executionId; the router throws instead of risking a double payment.

Utilities

Money parsing and provider selection helpers exported by the SDK.
