CORE ARCHITECTURE

Built for autonomous agents that spend real money.

Traditional API keys grant infinite spending power to hallucinating LLMs. EcoRouter introduces cryptographically bounded capability routing with deterministic micro-settlements.

01 / Deterministic Limits

Cryptographic Spending Mandates. No Runaway Bills.

Assign your agent a signed Ed25519 mandate specifying strict bounds: lifetime spend cap, maximum per-call fee, expiry timestamp, and allowed capability tags. If an agent loops or gets hijacked, the router hard-halts further calls before spending an extra cent.

  • ✓ Enforces per-hop micro-caps (e.g. $0.005 max per query)
  • ✓ Pre-signed session budgets verifiable on-chain
  • ✓ Automatic circuit breakers on latency or rate anomalies

02 / x402 V2 Protocol

Native Machine-to-Machine Settlement.

When your agent calls an external capability, the provider responds with HTTP 402 Payment Required. EcoRouter verifies the invoice against the active mandate, attaches the payment preimage, and retries the request seamlessly in under 60ms.

  • ✓ No credit card signups, no API subscriptions, no monthly minimums
  • ✓ Multi-chain settlement: Base, Solana, Arbitrum, Lightning
  • ✓ Cryptographic proof of receipt attached to execution payload

04 / Developer Experience

3 Lines of Code to Supercharge Any Agent.

Integrate EcoRouter into your existing LangChain, CrewAI, AutoGPT, or raw OpenAI agent in minutes. Wrap your standard fetch or use our typed SDK client.

agent.ts TypeScript 
import { EcoRouter } from 'ecorouter';

// 1. Initialize with agent mandate
const router = new EcoRouter({
  privateKey: process.env.MANDATE_SECRET,
  maxPerHop: 0.01 // $0.01 max
});

// 2. Execute capability without vendor API keys

  url: 'https://ecorouter.dev',
  extract: 'markdown'

Frequently Asked Questions

Everything you need to know about declarative capability routing and autonomous settlement.

What is EcoRouter and why can't I just use standard API keys? ＋
Standard API keys have no spending bounds or cryptographic isolation; if an autonomous agent enters an infinite retry loop or hallucinates malicious tool calls, it can drain thousands of dollars in minutes. EcoRouter introduces a declarative routing layer: your agent only requests abstract capabilities (e.g. 'web-crawl', 'python-sandbox'), while EcoRouter enforces signed per-hop budget mandates, arbitrates the cheapest/fastest provider, and settles payments autonomously via x402 V2.
How does the x402 V2 protocol work under the hood? ＋
When EcoRouter dispatches a capability request, an x402-compliant service responds with 'HTTP 402 Payment Required' along with payment terms (price, recipient address, and accepted tokens). EcoRouter validates these terms against the agent's pre-signed mandate, constructs an atomic payment proof or preimage, attaches it to the request header, and retries. The entire cycle finishes in under 60 milliseconds.
What payment rails, tokens, and networks are supported? ＋
EcoRouter natively supports micro-settlements on Base (USDC), Solana (USDC), Arbitrum, and Lightning Network. You can also run EcoRouter in zero-crypto 'Internal Credit Mode' using standard JWT quotas or team debit balances for enterprise environments.
How do budget mandates protect against prompt injection or hijacked agents? ＋
Budget mandates are signed using Ed25519 cryptographic keys prior to execution. Even if an attacker completely hijacks an agent's prompt, the router kernel verifies the cryptographic budget envelope on every outbound hop. The agent cannot spend more than its assigned per-hop limit or total session cap, and cannot invoke capabilities outside its whitelist.
Does EcoRouter replace Model Context Protocol (MCP) or work with it? ＋
EcoRouter works directly with MCP! Think of MCP as the standardized interface definition for tools and capabilities, while EcoRouter is the economic and routing runtime that sits between your agent and the MCP server. You can wrap any MCP server with EcoRouter to instantly monetize it or enforce spending controls.
Can I self-host EcoRouter in our VPC or air-gapped infrastructure? ＋
Yes. EcoRouter is 100% open source under Apache 2.0. You can run the lightweight daemon locally, as a sidecar container in Kubernetes, or embed it directly into your Node.js or Python backend using our zero-dependency SDK.
