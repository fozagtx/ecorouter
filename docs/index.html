Deterministic Economics

Pure mathematical optimization. Zero LLM hallucinations.

EcoRouter never uses an LLM to choose a provider. Every eligible offer is scored with mathematical reproducibility. The offer with the lowest economic cost wins, with deterministic tie-breaking on raw price and provider ID.

Scoring Formula:
economicCost = priceAtomic / (qualityScore × successRate)

On-Chain Mandates

Spending limits your agent physically cannot bypass.

The agent holds only a restricted ephemeral session key. The Soroban smart account independently verifies every payment on Stellar using __check_auth. Even if an agent hallucinates, enters an infinite loop, or is compromised, your capital remains completely safe.

  • ▲ Hard ceiling on cumulative budget and per-payment size
  • ▲ Cryptographic session expiry enforcement on-chain
  • ▲ Instant owner revocation at any time with one transaction
contracts/ecorouter-account — Soroban Mandate

Zero-Trust Defense

Local secrets. Strict SSRF protection. Atomic math.

Master keys and session secrets never leave your runtime environment. All provider URLs are vetted against loopback, private subnets, and cloud metadata endpoints to prevent server-side request forgery. Financial calculations use 64-bit integer atomic math to prevent rounding bugs.

  • ▲ Rejection of private, local, and metadata IPs (169.254.169.254)
  • ▲ Safe BigInt atomic accounting throughout pipeline
  • ▲ PAYMENT_SETTLEMENT_UNKNOWN halt mode prevents double-spend

Questions & Answers

Spending limits are enforced cryptographically on-chain by a Soroban smart account. The agent runtime only possesses an ephemeral session key. Before any token transfer executes, the contract's __check_auth hook verifies the per-transaction cap, total remaining budget, session expiration timestamp, and revocation state. If a spend violates the mandate, Stellar rejects the transaction at the consensus level.

No. EcoRouter is strictly local-first and non-custodial. There are no hosted databases, account registration systems, remote proxies, or centralized wallets. All keys remain on your machine, and transactions are signed locally and broadcast directly to Stellar.

V1 specializes in web.search, enabling autonomous agents to acquire real-time web discovery from multiple competing search providers. The router architecture is designed to accommodate additional deterministic capabilities such as code execution, data extraction, and model inference.

EcoRouter calculates the expected effectiveness (qualityScore × successRate) and computes economicCost = priceAtomic / expectedEffectiveness. The offer with the lowest economic cost is selected. If two offers tie, the lower raw price wins, followed by lexical provider ID sorting to guarantee 100% reproducible decisions.

Settlement occurs on the Stellar network using atomic units of USDC (with 7 decimal places). The SDK strictly performs accounting using JavaScript BigInt primitives to eliminate floating-point rounding errors.
