01

Parallel 402 Probes

Instead of committing blindly to one vendor, EcoRouter pings multiple capability providers simultaneously to inspect live payment challenges and latency.

02

Hard Spend Limits

Set maxSpendUsdc on every execution. Any provider quoting above your policy threshold is immediately rejected.

03

Local & Idempotent

Runs directly in your application runtime. Every request takes an optional executionId to guarantee safe idempotent retries.

quickstart.ts 
import { EcoRouter } from "ecorouter";

// Configure router with payment credentials and redundant providers
const router = new EcoRouter({
  account: process.env.STELLAR_ACCOUNT,
  sessionSecret: process.env.SESSION_SECRET,
  providers: [
    { id: "tavily", capability: "web-search", endpoint: "https://api.tavily.com/x402", qualityScore: 0.95 },
    { id: "brave", capability: "web-search", endpoint: "https://api.brave.com/x402", qualityScore: 0.90 }
  ]
});

// Route capability with strict policy bounds
const result = await router.execute({
  capability: "web-search",
  input: { query: "latest open source agent protocols" },
  policy: { maxSpendUsdc: "0.01", minimumQuality: 0.85 }
});

console.log(result.providerId, result.spentUsdc, result.data);

FAQ

What is EcoRouter? ＋
EcoRouter is an open-source TypeScript SDK that handles capability discovery, provider arbitrage, and x402 payment settlement directly in your application process.
How does provider selection work? ＋
When you call execute(), EcoRouter queries all registered providers for that capability in parallel, checks their 402 challenge terms against your spending policy, and selects the optimal provider based on price and quality.
Is there a centralized server or proxy? ＋
No. EcoRouter runs locally inside your agent runtime. Your credentials, policies, and requests never pass through third-party servers.
How does it prevent overspending? ＋
Every execution accepts a maxSpendUsdc policy. If all providers quote above your maximum limit, EcoRouter aborts the call with a NoEligibleProviderError before making any payment.
