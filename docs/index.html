01 · Why Stellar

Agents get a wallet with rules they cannot break

An agent that pays for APIs on a normal key can drain it in one bad loop. On Stellar the spending rules are written into the agent's own Soroban account, so every payment is checked on chain before it settles.

01

The budget lives in the contract

A Soroban smart account checks every payment in __check_auth. A leaked session key still cannot spend past the mandate.

02

USDC is native on Stellar

Agents pay providers in USDC through the Stellar Asset Contract, with amounts kept in exact 7 decimal integer units.

03

Settlement fits a request

Ledgers close in seconds and fees are a fraction of a cent, so paying per API call actually makes sense.

02 · The runtime

Ask for a capability, not a vendor

Your agent says it needs web.search. EcoRouter finds who sells it, compares live prices, pays the best one in USDC on Stellar and hands back the same result shape every time.

Primitive 01 PARALLEL

Ask every provider at once

Each provider for a capability gets an x402 probe in parallel. Slow or broken ones time out after five seconds and drop out.

Primitive 02 POLICY

A hard limit on every call

Each execute() carries maxSpendUsdc and minimumQuality. Quotes above the limit never reach the payment step.

Primitive 03 LOCAL

Runs inside your agent

No hosted proxy or registry. Keys stay in your process, and an executionId makes retries safe.

Quickstart / search-agent.ts 
import { EcoRouter } from "ecorouter";

const router = new EcoRouter({
  account: process.env.ECOROUTER_ACCOUNT!,
  sessionSecret: process.env.ECOROUTER_SESSION_SECRET!,
  paymentClient, // your local Stellar x402 client
  providers: [
    { id: "search-a", capability: "web.search", endpoint: process.env.SEARCH_A_URL!, qualityScore: 0.82 },
    { id: "search-b", capability: "web.search", endpoint: process.env.SEARCH_B_URL!, qualityScore: 0.93 }
  ]
});

const result = await router.execute({
  capability: "web.search",
  input: { query: "latest lithium carbonate prices" },
  policy: { maxSpendUsdc: "0.05", minimumQuality: 0.8 }
});

console.log(result.decision.providerId, result.payment.transactionHash, result.mandate.remainingUsdc);

04 · FAQ

Questions

What is EcoRouter?

An open source TypeScript SDK that lets an agent buy capabilities like web search over x402, pay in USDC on Stellar, and stay inside a budget enforced by its own Soroban smart account.

Why does it run on Stellar?

Soroban smart accounts can run custom authorization in __check_auth, so the spending rules sit in the agent's account itself. USDC is native on Stellar and settlement is fast and cheap enough to pay per request.

What stops an agent from overspending?

Two layers. The SDK rejects any quote above maxSpendUsdc before paying, and the Soroban account rejects any transfer above max_payment, past total_limit, after expires_at or once revoked.

How is a provider chosen?

Every eligible quote gets an economic cost of price divided by qualityScore times successRate. The lowest cost wins, then the lower price, then the provider id. No model is asked to decide.

Is there a hosted server or custody?

No. The SDK runs in your process, your session secret never leaves it, and funds stay in the Soroban account you own and can withdraw from at any time.

Which network does it support today?

Stellar testnet with USDC. Challenges for any other network or asset are rejected as invalid.
